# 上手与工程集成

[返回首页](../README.md) · [源码导航](source-map.md)

本仓库保存了 2U 立方星项目的应用源码、驱动和实验版本。它是**源码与设计资料快照**，目前没有完整的可直接导入、编译和烧录的固件工程。

## 先确认开发环境

| 项目 | 仓库中可以确认的内容 |
| --- | --- |
| 主控平台 | `isr.c` / `isr.h` 的文件头标注 **CH32V307VCT6**；应用程序使用 `SYSTEM_CLOCK_144M` |
| 底层库 | 多个文件包含 `zf_common_headfile.h`，依赖 SEEKFREE（逐飞）库及对应芯片 SDK |
| IDE 线索 | 中断文件头记录 **MounRiver Studio V1.8.1**，这是原始文件的环境信息，并非已验证的唯一兼容版本 |
| 算法 | 仓库包含 Mahony AHRS / IMU 实现，以及多个 PID 与电机控制实验版本 |
| 源文件编码 | 部分 C / H 文件采用 GBK 兼容编码；中文注释乱码时，先以 GBK / GB18030 重新打开 |

仓库尚未包含 `zf_common_headfile.h` 等完整底层库、启动文件、链接脚本及 IDE 工程配置。请先取得与实际开发板匹配的原始工程或 SDK，并确认工具链和下载器配置；现有文件不足以给出经过验证的一条命令构建流程。

## 选择一个实验入口

仓库共有 **11 个包含 `main()` 的 C 文件**。每个构建目标只选择其中一个，按需加入驱动和算法文件，避免将全部 `*.c` 同时编入工程。不同版本还会重复定义全局变量、串口回调和定时器回调。

| 想先了解或验证什么 | 建议阅读的入口 |
| --- | --- |
| 姿态采集、编码器反馈与电机控制 | [`main.c`](../main.c) |
| 控制参数与串口指令实验 | [`main_newpid.c`](../main_newpid.c) |
| MPU6050 姿态数据与 LoRa 串口输出 | [`main_loraTEST.c`](../main_loraTEST.c) |
| HMC5883 / QMC5883 磁力计 | [`main_HMC5883test.c`](../main_HMC5883test.c) / [`main_QMC5883test.c`](../main_QMC5883test.c) |
| GNSS 数据解析 | [`GPS.c`](../GPS.c)，它也是独立入口 |
| 摄像头控制与 LoRa 回传流程 | [`main_lora_and_camera.c`](../main_lora_and_camera.c) |

入口文件的完整说明见[源码导航](source-map.md)。文件名代表保留的实验版本，不表示其已经通过统一的系统集成验证。

## 推荐集成顺序

1. **验证基础工程。** 在匹配的 SDK 工程中先确认时钟、调试串口和下载流程，再引入本仓库的应用代码。
2. **选定入口与依赖。** 保留一个 `main()`，按该入口需要加入 `MahonyAHRS.c`、磁力计驱动等文件，配置头文件搜索路径。
3. **核对中断连接。** 当前 [`isr.c`](../isr.c) 将 `TIM2` 接到 `pit_handler()`、`USART3` 接到 `uart_rx_interrupt_handler()`；`USART1` 中对应的用户回调已注释。切换实验时同步核对回调定义和串口选择。
4. **验证传感器与数据链路。** 先检查原始传感器值、坐标方向和串口数据，再观察姿态解算结果。各版本的 UART 波特率并不统一。
5. **校准控制时序与参数。** 将 Mahony 算法采样频率、实际调用周期、编码器测速周期和 PID 参数作为同一组配置检查。
6. **逐步接入执行机构。** 根据实际接线核对电机方向、PWM 有效电平及限幅，再进行单轴与多轴调试。

## 接口与参数核对点

以下是**源码配置的阅读索引**，不是适用于所有硬件版本的接线表。

| 接口 / 参数 | 源码中的配置与差异 |
| --- | --- |
| LoRa 串口 | 多个版本使用 `UART3`、TX `B10`、RX `B11`；`main.c` / `main_loraTEST.c` 为 9600，`main_newpid.c` / `scan.c` / `scan2.c` 为 115200 |
| 摄像头串口 | `main_lora_and_camera.c` 使用 `UART2`、TX `A2`、RX `A3`，波特率 115200，包含 VC0706 指令流程 |
| 电机 PWM | `main.c` 使用 `TIM4` 的 `D12`–`D15` 通道；通道与电机轴的对应关系需结合实际接线确认 |
| 引脚复用 | `main.c` 同时将 `A7` 定义为电机方向引脚和一个编码器输入，集成前需要核对并解决该冲突 |
| 磁力计 I²C | `hmc5883.h` / `qmc5883.h` 配置 SCL `B4`、SDA `B6`；部分主程序还将 `B4` 用作 LED，不能直接合并配置 |
| 姿态解算周期 | `MahonyAHRS.c` 中 `sampleFreq` 为 1000 Hz；`main.c` / `main_newpid.c` 的定时器配置为 100 ms，`main_loraTEST.c` 为 10 ms，需要统一 |
| GNSS 型号 | `GPS.c` 注释提及 ATGM336H，但初始化调用为 `gnss_init(TAU1201)`；以实物和对应 SDK 接口核对型号 |

`main.c` 和 `main_newpid.c` 调用的是 `MahonyAHRSupdateIMU()`。磁力计有独立驱动和测试入口，但这不等于主程序已经接入完整的九轴融合。`GPS.c` 中用于遥测的浮点数据赋值仍被注释；摄像头文件也应作为待核对的实验流程阅读。
